# 🏥 CareConnect - Smart Healthcare App

CareConnect is a modern Android healthcare application designed to simplify medical services in one platform.

---

## 🚀 Features

### 🩺 Doctor Appointment
- Book appointments with doctors
- Select date & time
- View upcoming appointments

### 💊 Medicine Order
- Add medicines to cart
- Place orders easily
- Track order history

### 🧪 Lab Tests
- Book lab tests (Blood, X-ray, MRI, etc.)
- View lab order history

### 📚 Health Articles
- Read latest health news (API integrated)
- Image-based article cards
- Share articles

### 💳 Payment System
- Simulated payment flow
- Receipt generation

### 🔐 Authentication
- Login / Register system
- Session management

---

## 🛠️ Tech Stack

- Java (Android)
- MVVM Architecture
- Room Database
- Retrofit API
- Glide (Image Loading)

---


## ⚙️ Installation

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run the app

---
